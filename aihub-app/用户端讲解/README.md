## 一分钟版本

这个前端小得多（10 个页面 + 3 个公共模块），但**含金量集中在 common/stream.js**：
一套"NDJSON 流式对话"要在 H5（fetch + ReadableStream）和小程序（uni.request enableChunked）
两个完全不同的运行时上跑通，还要处理半包、UTF-8 手写解码、中断、401——
它是"后端 NdjsonStreamSink"的镜像前端，两端合起来才是完整的流式链路。
