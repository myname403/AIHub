# 第二轮：记忆卡片与动手实验

## 1. 总口诀

**"一张路由表(pages.json)、三件公共服(config/request/stream)、两把斧(pop 与 flush)、两条腿(H5 与小程序)"**

## 2. 六张卡片

**卡 1｜uni-app 路由不是 vue-router**：页面必须在 pages.json 注册，跳转用 `uni.navigateTo/reLaunch`；tabBar 也在这里配。
**卡 2｜条件编译是编译期裁剪**：`#ifdef H5` 之间的代码在小程序包里根本不存在——不是 if 判断。
**卡 3｜为什么 NDJSON 不用 SSE**：EventSource 带不了 Authorization 头 + 小程序没有 EventSource → 行协议 + POST 通吃。
**卡 4｜半包两板斧**：`split('\n')` 后 pop 留半包；结束 flush 收无换行的尾帧。忘任何一个是"最后一条消息丢失"。
**卡 5｜停止=两步**：本地 abort + 远端 `/api/ai/agent/cancel`；客户端断开不等于服务端停止。
**卡 6｜小程序手写 UTF-8 解码**：没有 TextDecoder；中文 3 字节，按首字节高位判断字节数（<0x80/<0xe0/<0xf0/其余 4 字节）。

## 3. 动手实验

**实验 1｜亲眼看半包**
H5 打开对话页 → F12 Network → 找 `/api/ai/chat/ndjson` → EventStream/Response 标签：
观察响应是**一行一个 JSON 逐行出现**；再在 Sources 里给 stream.js 的 `handleChunk` 打条件断点，
看 buffer 里出现"半行 JSON"被 pop 回去的瞬间。

**实验 2｜停止按钮的信令完整性**
发起一个 agent 场景长任务 → 点"停止" → Network 里应看到**两个动作**：
ndjson 连接终止 + 一条 `POST /api/ai/agent/cancel`。
再去查 `ai_agent_task` 表该任务 status——是"已取消"而不是"跑完了"（服务端真的在步骤边界停了）。

**实验 3｜401 统一处理**
登录后手动改坏 localStorage/存储里的 token → 发一条对话 →
应弹"登录已过期"并自动跳回登录页（request.js/stream.js 的 handleUnauthorized 分支），
全程没有任何页面级 if 判断——这就是"统一收口"的价值。

**实验 4｜双端一致性（有微信开发者工具再做）**
`npm run dev:mp-weixin` → 工具里导入 `dist/dev/mp-weixin` → 同一账号对话：
流式逐字效果应与 H5 一致（除了小程序无 TextDecoder 走手写解码）；
config.js 里把小程序 baseUrl 改成你局域网 IP 才能连通（手机真机同 WiFi）。

## 4. 自测五问

1. 新增一个页面要改哪个文件？（pages.json 注册路径 + 建 .vue；tab 页改 tabBar）
2. rag.sources 事件是干嘛的？（渲染"回答引用了哪些文档分片"，RAG 可信度的前端呈现）
3. modelCode 传空会发生什么？（后端按管理端配置的"场景路由"选模型——前端不指定=听配置的）
4. 为什么 H5 的 baseUrl 用 localhost:8080 直连网关而不是相对路径？（5173 与 8080 不同源，靠网关 globalcors 放行；和 admin-ui 的 vite proxy 是两种跨域方案——可对比记忆）
