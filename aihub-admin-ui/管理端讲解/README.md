## 一分钟版本

pure-admin 给了一个"骨架齐全"的后台模板，AIHub 的改造集中在**三处接线**：
1. **http 层**：拦截器把后端 `R{code,message,data}` 解包成 `data`，401 统一处理登录过期；
2. **登录层**：`api/user.ts` 把 AIHub 的"租户码+用户名+密码"登录响应**伪装组装**成 pure-admin 期望的 UserResult 结构——框架一行没改，契约在适配层消化；
3. **路由层**：`api/routes.ts` 把后端菜单树（M/C/F）翻译成 pure-admin 动态路由（F 按钮被过滤，只进权限码）。

**记住这个模式：不改开源框架源码，全部适配收敛在自己写的薄层里**——升级框架不丢改动。
