## 1. Java 基础与集合

## 7. 安全

| 考点 | 项目落点 |
|---|---|
| JWT 原理/无状态 | 三段结构、验签链路、过期与无法作废的权衡 |
| BCrypt vs MD5 | 同密码不同哈希 demo；盐与慢哈希 |
| 越权防御（IDOR） | 强制剥离伪造头 + mustGetOwn 归属校验 |
| 防爆破 | 验证码一次性消费 + fail-fast |
| 密钥管理 | AES-GCM 加密落库、HMAC 哈希存储、常量时间比较 |

## 9. 讲故事的 STAR 模板（把项目讲成故事）

```
S 情境：绑定知识库的应用所有对话卡死在"思考中"
T 任务：定位并修复，不能引入新的单点故障
A 行动：jstack 线程转储 → 定位 RAG 检索阻塞 → 根因是嵌入模型默认连外网
   → 双修复：本地嵌入模型显式配置 + 3 秒超时降级保护
R 结果：绑定应用恢复正常；顺带建立"可选能力绝不拖死主链路"的设计原则
```

这个模板套用本项目任何一个修复案例（CORS 预检、NDJSON 网关缓冲、120 秒截断、
验证码防爆破、VO 重构防敏感泄露）——每个 bug 修复记录都在学习文档 07 里。
