## 三条阅读路线

- **面试速成**（时间紧，3~4 天）：`01` 建立全局 → `08` 吃透五条链路 → `10`/`11` 补前端纵深 → `12` 背排障故事 → `13` 收口刷自测清单
- **系统学习**（想彻底吃透代码）：`01` → `03`~`07` 逐模块精读 → `08` 串联验证 → `09` 注解查漏 → `02`/`10`/`11`/`12` 按需延伸
- **运维部署**（先把环境跑起来）：`02` 第 7 节一键拉起 → `01` 理解拓扑 → `08` 用链路验证部署正确性
