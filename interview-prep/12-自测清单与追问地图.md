## 三、20 题 30 秒速答（考前突击用）

1. **为什么 AI 能力内聚成一个服务？** → 规避分布式事务、流式跨服务传递、Agent 跨服务编排三难题；服务间只留三类无事务调用。
2. **domain 层零框架依赖怎么做到的？** → 定义 SPI 端口（接口），infra 提供实现；Spring AI 类型全部锁在 `infra.ai`。
3. **Agent 怎么防止跑飞？** → 三重预算（子任务 3 / Token / 超时 180s），`AtomicLong` 累加，每步前检查。
4. **取消是怎么实现的？** → 内存 Set 存 conversationId 的标志位协作，**只在步骤边界生效**，打不断在飞的 HTTP。
5. **多租户怎么隔离？** → 四道防线：只认 JWT / 网关防伪造 / 查询强制过滤 / 出口 TenantGuard。
6. **配额怎么保证原子？** → `INSERT ... ON DUPLICATE KEY UPDATE used_value = used_value + n`，靠唯一键。
7. **配额并发会超扣吗？** → 会，非事务两阶段；改进走 Redis Lua / 预扣释放。
8. **RAG 分片为什么要有重叠？** → 防止语义被切断在边界（一句话跨两个分片）。
9. **引用怎么做到刷新后还能查？** → 落 `ai_message_reference`，按 `(tenant_id, conv_key, assistant)` 归属最后一条消息。
10. **模型输出不是合法 JSON 怎么办？** → 硬截取 + Jackson 解析 + 失败降级为单个子任务。
11. **小程序为什么不用 SSE？** → 不支持；用 `enableChunked`，且要禁 gzip（否则收不到增量）。
12. **H5 为什么不用 EventSource？** → 无法携带自定义 Header（带不了 Authorization）。
13. **ChatClient 缓存怎么做的？** → CHM + DCL + TTL 60s，key 四段；CHM 提供可见性，不需要 volatile。
14. **配置热更新失效过吗？** → 有，record / 构造器绑定无法重绑定，会静默失效。
15. **MCP 三种传输区别？** → SSE 两次握手、streamable 单端点 `/mcp`、stdio 走进程通道。
16. **MCP stdio 最大的坑？** → stdout 就是协议通道，banner/日志会污染；必须关 banner + 日志改 stderr。
17. **超时怎么设？** → 分层收紧：MCP 70s > HTTP 60s；外层必须大于内层。
18. **指标标签为什么不放租户 ID？** → 基数爆炸，Prometheus 会崩；高基数信息放日志用 TraceId 关联。
19. **浏览器 Agent 为什么不用 Playwright？** → 要下载内核 + 重依赖；用 JDK 自带 WebSocket 直连 CDP，复用本机 Chrome。
20. **项目最大的遗憾？** → 多租户没有框架级兜底（无 TenantLine 拦截器），靠约定不可靠。

## 四、★ 追问地图（演示三条完整追问链）

### 链 1：项目介绍 → 多租户（最容易被深挖）

```
"介绍一下项目"
→ "多租户怎么实现的？"
   → "租户 ID 从哪来？"                    （JWT，不接受前端传参）
   → "前端能不能伪造？"                     （网关先 remove 再 set）
   → "那每个查询都要手写 tenant_id？"        （是）
   → "漏写了怎么办？"                       （★ 没有兜底！）
   → "你怎么解决？"                         （TenantLineInnerInterceptor + ArchUnit 禁止裸 SQL + 交叉租户测试）
   → "那向量检索呢？"                       （过滤表达式下推 + 出口 TenantGuard）
```

**这条链的关键在第 5 问**——说出"没有兜底"并给出改进方案，是 L4 的答案。

### 链 2：RAG → 工程细节

```
"RAG 怎么做的？"
→ "分片多大？为什么？"                      （500/重叠 100）
→ "重叠有什么用？"                          （防止语义切断）
→ "检索到不相关内容怎么办？"                 （阈值 0.6 + 提示词"不知道就说不知道"）
→ "检索慢怎么办？"                          （3s 超时降级为普通对话）
→ "降级后用户不知道为什么没引用，能接受吗？"   （可以，可用性好于正确性；后续可提示"检索超时"）
→ "效果怎么评估？"                          （★ 没做系统评测 → 讲 RAGAS / 召回率 / 人工反馈闭环）
```

### 链 3：Agent → 可控性

```
"Agent 怎么实现的？"
→ "任务怎么拆？"                            （模型返回 JSON 数组）
→ "模型返回不规范怎么办？"                    （硬截 + 降级）
→ "会不会死循环/跑飞？"                      （三重预算）
→ "Token 怎么统计？"                        （AtomicLong + 响应 usage）
→ "用户想中途取消呢？"                       （标志位）
→ "能立刻停吗？"                            （★ 不能，只在步骤边界；在飞的 HTTP 打断不了）
→ "怎么才能立刻停？"                         （独立 Future + cancel(true) + 关 Socket + readTimeout）
→ "多实例下呢？"                            （★ 内存 Set 失效，要改 Redis）
```

**第 6、8 问是分水岭**——能主动说出限制的人，才是真正做过的人。

## 五、照妖镜汇总（面试前最后看一遍）

**收尾轮（2026-09）已修掉一批，务必分清"现在能讲什么"。**
完整对照表见 [09](09-项目难点与STAR故事库.md) 的"别吹过头清单"。

### ✅ 现在可以讲（已修复，含验证边界）

1. **Outbox 落地** —— 端口 + 落库 + 守护线程重投，`reportUsage` 失败转交；9 个单测；
   **要主动讲"重投前补齐租户上下文"这个坑**；
2. **租户 SQL 兜底已实现**（`TenantLineInnerInterceptor` + 白名单）——**但默认关闭**，
   理由是"单测 mock 覆盖不到真实 SQL 改写，我不想拿没在真库跑过的东西当默认行为"；
3. **`task` 维度配额真正拦截**（同步抛异常 / 流式发 error 事件），降级放行语义保留；
4. **`PlanningAgent` finally NPE** 兜底、**`browser.max-steps` 生效**（补了回归用例）、
   **`initialize-schema` 配置真正生效**、**供应商协议族判定补齐 ollama**；
5. **ArchUnit 4 条 → 7 条**（domain 禁全部 Spring/Jackson、application 禁 Spring AI、底层 infra 不得反向依赖 AI 层）；
6. **前端**：移除会把 mock 打进生产包的 fake-server、补 Nginx 反代（容器里 `/api` 原本 404）、
   axios 读取 `X-Trace-Id`、H5 侧 `AbortController` 真正中断 + 冲刷尾帧。

> **交付证据**：全量回归 **315 个用例全绿**（ai-service 185 / platform 49 / common 30 /
> mcp-service 42 / mcp-sse 8 / mcp-stdio 1），40 个测试类 + 2 个需真实环境的 IT。

### ❌ 仍然别吹（未做）

1. ECharts —— 装了但**注册被注释**，用量看板用 `el-table` + `el-progress`；
2. Pinia 的 6 个 store —— **全是模板原版**；管理端业务接口**未下沉 `api/` 层**（在 `.vue` 里裸调）；
3. 前端单测、系统化 AI 评测集 —— **都没有**；
4. 租户兜底**未在真实 MySQL 上回归**（所以默认关）；跨租户端到端回归测试**没有**；
5. 分库分表、SkyWalking、MQ —— **都没上**（能讲方案）。

**使用方式**：被问到时**主动说"这块我还没做/我做到哪一步，我的方案是……"**。
主动承认 = 诚实 + 有规划；被戳穿 = 灾难。
**修好的也别吹过头**——一定要带上"我验证到哪一步"，那才是可信度来源。
