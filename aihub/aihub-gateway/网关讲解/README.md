## 一分钟版本（先有个印象再进第一轮）

网关 = **小区门口的保安亭**。它不干活（无数据库、无业务），只做四件事：

1. **盖邮戳**（TraceIdGlobalFilter）：给每个请求发一个全链路唯一的编号；
2. **查证件**（AuthGlobalFilter）：验 JWT 或 API Key，查不过去直接拒之门外（401）;
3. **发工牌**（AuthGlobalFilter 的另一半）：查证通过后，把"你是几号租户的"写进请求头，下游只认工牌不认嘴；
4. **指路**（application.yml 的 routes）：按 URL 前缀告诉你该去 8081 还是 8082。
