# 第二轮：记忆卡片与动手实验

## 2.1 总口诀（先背这个）

**"两信封、一异常、俩储物柜、三把锁、一个补丁"**

| 口诀 | 对应包/类 |
|---|---|
| 两信封 | R（响应信封）、ResultCode（信封上的编号段） |
| 一异常 | BizException + GlobalExceptionHandler（抛与接） |
| 俩储物柜 | TenantContext、TraceContext（都是 ThreadLocal，都要 clear） |
| 三把锁 | JwtVerifier（验）、ApiKeyCodec（哈希）、AesGcmTextCipher（可逆加密） |
| 一个补丁 | JacksonLongToStringConfig（雪花 ID → 字符串） |

## 2.2 六张卡片

**卡 1｜为什么 BizException 继承 RuntimeException？**
非受检——业务层随便抛、层层上飞、兜底网统一接；受检异常会逼每层写 try-catch。

**卡 2｜ThreadLocal 三件套是什么？**
`set`（拦截器入口）→ `get`（任意深度业务）→ `clear`（afterCompletion 必须做）。
漏 clear 的事故名叫"**串台**"：线程复用把 A 租户的上下文带给了 B。

**卡 3｜下游为什么敢信 X-Tenant-Id？**
信任链：网关验令牌 → 撕伪造头 → 写可信头 → 下游拦截器读取。
前提：**服务端口不对公网开放**，所有流量必经网关（standalone 直连模式下这条链是断的，属已知妥协）。

**卡 4｜MDC 是什么，业务代码零改动怎么做到的？**
logback pattern 里的 `%X{traceId}` 从 MDC 取值；TraceContext.set 时双写（ThreadLocal + MDC），所以每行日志自动带 ID。

**卡 5｜三种"哈希/加密"怎么选？**
只要验证不要还原 → HMAC 哈希（ApiKeyCodec）；要还原给第三方用 → AES-GCM 可逆加密（模型 Key）；防篡改的自包含凭证 → JWT 签名。

**卡 6｜雪花 ID 为什么会"对不上"？**
19 位 Long > JS 安全整数 2⁵³-1，JSON 数字解析时末几位被抹。修法：全局序列化成字符串（不是前端 toFixed，也不是缩短 ID）。

## 2.3 三个动手实验（服务都在跑，直接做）

**实验 1｜观察 R 信封的三种形态**
```powershell
curl.exe -s http://127.0.0.1:8080/actuator/health          # 不是 R（actuator 不归业务管）
curl.exe -s http://127.0.0.1:8080/api/platform/system/user/page   # 网关 401：R 格式但 HTTP 401
```
再到浏览器登录管理端，F12 看任意 `/api/platform/` 响应：`{code:0,message,data,traceId}`。
**结论**：三种来源（actuator/网关/业务）两种格式，前端拦截器要都认识。

**实验 2｜traceId 全链路接力**
```powershell
curl.exe -si -H "X-Trace-Id: demo-001" http://127.0.0.1:8080/api/platform/system/user/page
```
响应头 `X-Trace-Id: demo-001`（网关沿用）；然后去 IDEA 的 platform 控制台日志里搜 `demo-001`——
401 发生在网关所以 platform 没有日志；换成登录后的真令牌打一次，platform 日志里就会出现带 `demo-001` 的行（MDC 生效）。

**实验 3｜雪花 ID 精度丢失复现（30 秒理解 Jackson 补丁的存在意义）**
PowerShell 里执行：
```powershell
[double]"2106668143920308226"
```
输出 `2106668143920308224`——末位已经变了！这就是 JS 拿到 JSON 数字后会发生的事（JS Number 同款双精度浮点）。
再看库里真实值：`docker exec aihub-mysql mysql -uroot -proot123456 -e "select id from aihub_platform.sys_tenant where code='12'"` → `...226`。
**补丁没打之前，前端拿着 ...224 来回传，后端查无此人。**

## 2.4 自测五问

1. 新写的接口返回 `Map.of("ok",true)` 违反了哪条规矩？（必须 R 信封）
2. Service 里 `TenantContext.getTenantId()` 返回 null，第一嫌疑是什么？（拦截器没注册/路径没被拦截/异步线程切换没 wrap）
3. 为什么 GlobalExceptionHandler 管不到网关？（WebFlux 没有 @RestControllerAdvice 那套 MVC 机制）
4. 用户忘了 API Key 能帮他找回吗？（不能，只存哈希，只能重置）
5. Long 转字符串的补丁对网关响应生效吗？（不生效也不需要——网关不序列化业务实体）
